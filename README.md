# Garland

 Этот проект основан на проекте 'Christmass Light' by AlexGyver, который в свою очередь, базировался на проекте 'Notamesh', который был переработан из проекта Andrew Tuline, на Ардуино NANO и адресной ленте/гирлянде WS2812b.
 Я перевёл проект на ESP8266. Постарался сохранить идентичность эффектов и дополнений, лишь чуточку добавив :)
